# Task Management REST API

## Overview

A backend Task Management System developed using Python, Flask, and SQLite.

## Features

- Create tasks
- View all tasks
- View an individual task
- Update tasks
- Delete tasks
- Input validation
- Error handling
- SQLite database integration
- REST API endpoints
- Appropriate HTTP status codes
- Parameterized SQL queries

## Technologies

- Python 3
- Flask
- SQLite
- REST API
- Postman
